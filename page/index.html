oc2api on Vercel

Sign in to Vercel once: every project named oc2api* becomes a seat, rotated automatically.

How it works

  1. Sign in once per Vercel account in the provider row.
  2. Every Vercel project whose name mentions oc2api is taken as a seat.
  3. Requests rotate over the seats, skipping one that is out of its free tier.

This plugin never deploys or changes a project: it only reads.

The two repositories

  • oc2api https://github.com/zhuweiyou/oc2api

    The thing you deploy to Vercel: one project per exit. This plugin only reads those projects.

  • magpie-oc2api https://github.com/zhuweiyou/magpie-oc2api

    This plugin: how it works, what it reads, and how to install it in another magpie.
